# Brand asset provenance

These locally hosted logos identify hardware vendors, compute providers, and
software used by QuantumPad. They do not imply affiliation or endorsement.

`sources.json` records the original public URL, SHA-256 of the stored asset,
and attribution for every image. Provider assets come from their official
websites. Hardware and framework SVGs come from Simple Icons under CC0;
its license is included here. Logo trademarks remain with their owners.

Simple Icons SVGs use the corresponding brand color. Official provider artwork
is unmodified. Images retain their aspect ratio and are not recolored with CSS.
Generic CPU compute retains a generic icon because no vendor is specified.

Retrieved 2026-10-04. Use the existing wallet assets in `/wallets` for wallets.
